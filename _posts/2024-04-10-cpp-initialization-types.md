## 一、类型分类与初始化的关系

C++ 中，对象、引用、函数和表达式都有类型。类型规定了实体可以执行的操作，也影响初始化、赋值和生命周期规则。初始化语法的完整规则见[C++ 初始化详解](./2024-04-16-cpp-initialization-semantics.md)；本文聚焦类型分类及其对这些规则的影响。

C++ 初始化有默认、复制、直接和列表等形式。不同语法会根据目标类型进入不同的初始化路径。具体规则、`initializer_list` 优先级、聚合初始化和缩窄转换见[C++ 初始化详解](./2024-04-16-cpp-initialization-semantics.md)。

## 二、类型来源

### 1、基础类型

基础类型（fundamental type）由语言直接提供，包括算术类型 `int`、`float`、`char`、`bool`，以及 `void` 和 `nullptr_t`。

### 2、复合类型

复合类型（compound type）由已有类型组合而成，包括指针、引用、数组、函数类型、枚举、类、结构体和联合体。例如 `int*`、`int&` 和 `int[10]` 都不是基础类型。

## 三、类型的常用语义分类

标准还按类型的表达能力和对象模型进行分类。**标量类型**包括算术类型、枚举、指针、成员指针和 `nullptr_t`；它们表示单一值。**聚合类型**则满足标准规定的聚合条件，通常可通过列表初始化按成员顺序初始化。聚合条件会随语言版本变化，不能简单等同于“没有任何构造函数的类”。

| 类型示例 | 来源分类 | 常用语义分类 | 说明 |
|----------|----------|--------------|------|
| `int` | 基础类型 | 标量 | 表示一个整数值 |
| `int*` | 复合类型 | 标量 | 表示一个地址值 |
| `int&` | 复合类型 | 引用类型 | 是对象的别名，不是独立对象 |
| `int[10]` | 复合类型 | 聚合 | 包含十个连续元素 |
| `std::string` | 类类型 | 非标量类类型 | 生命周期和资源由类定义管理 |

“Primitive Built-in Types”是部分教材为便于教学使用的分类，不是 C++ 标准中的正式分类名称。更多定义可参阅 [Type](https://en.cppreference.com/w/cpp/language/type-id.html) 和 [Overview of data objects](https://www.ibm.com/docs/en/xl-c-and-cpp-aix/13.1.3?topic=odod-overview-data-objects)。

## 四、指针与引用

### 1、指针

指针从类型来源看是复合类型，从标量分类看通常是标量类型。复制指针通常可按标量值复制，复制的是地址，不会自动复制所指向对象；这不等于并发语境下的原子访问。是否能安全访问目标对象，还取决于生命周期、所有权和同步规则。

全局或静态存储期的指针会经过零初始化，结果为 null pointer value；局部未初始化指针的值不确定，读取它会产生未定义行为。

### 2、引用

引用属于复合类型，是已存在对象的别名，必须在初始化时绑定，之后不能重新绑定。对引用取地址得到被引用对象的地址。

编译器常见的实现模型是用指针保存绑定关系，但这是实现模型，不是语言层面的等价定义。引用没有独立的对象身份，不能据此推导出所有指针操作都适用于引用。

```cpp
int value = 10;
int& ref = value;
ref = 20; // 修改 value
```

| 特性 | `int` 对象 | `int*` 对象 | `int&` 引用 |
|------|------------|-------------|-------------|
| 来源分类 | 基础类型 | 复合类型 | 复合类型 |
| 是否是对象 | 是 | 是 | 引用是别名，不是独立对象 |
| 是否必须初始化 | 局部对象可默认初始化，但值可能不确定 | 否，但未初始化值不确定 | 是 |
| 是否可重新绑定 | 不适用，赋值改变值 | 可以改变指针值 | 不可以 |

## 五、定义位置对初始化的影响

对内置类型而言，存储期很重要：静态存储期对象先进行零初始化；局部自动存储期对象若没有初始化器，值不确定。类类型则按其构造函数和成员初始化规则建立对象，定义位置不能替代构造函数逻辑。

```cpp
class MyData {
    int x = 0;
    double y{0.0};
};
```

类内初始值让成员的默认状态由类型定义决定，而不是依赖对象位于全局还是局部。若构造函数初始化列表为成员提供了值，则以该初始化为准。

## 六、Most Vexing Parse

在声明语句中，若一种写法既能解释为对象定义又能解释为函数声明，标准要求优先按函数声明解释：

```cpp
Timer timer(); // 函数声明，不是对象初始化
Timer timer{}; // 对象定义和值初始化
```

这是初始化语法与声明语法相互作用的结果。更多关于 `T x()`、列表初始化和重载解析的规则见[C++ 初始化详解](./2024-04-16-cpp-initialization-semantics.md)。
